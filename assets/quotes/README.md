# 名人照片放這裡（可選）

每日金句卡預設使用「縮寫圓形頭像」（零版權風險）。
若想改用真實照片，把檔案放進此資料夾，命名為 `<id>.jpg`：

例如：
- assets/quotes/andrew-ng.jpg
- assets/quotes/fei-fei-li.jpg
- assets/quotes/edsger-dijkstra.jpg

id 對應 assets/quotes.js 裡每筆的 `id` 欄位。
前端會自動偵測：有照片用照片，沒有就退回縮寫圓。

⚠️ 版權提醒：公開商用網站請只用「公眾領域」或「CC 授權」的照片
（例如 Wikimedia Commons 標示可商用者），避免使用新聞社/Getty 圖庫照。
